# Agent Bridge 键盘功能简要说明

> 状态：Draft v0.1  
> 日期：2026-08-06  
> 用途：向硬件开发方和体验人员说明各个物理按键及控件的默认功能  
> 说明：本文描述默认布局；Command Key、摇杆和旋钮的部分功能可在 Agent Bridge App 中调整

## 1. 整体布局

Agent Bridge 共有 13 个 MX 按键、1 个 Profile 键、1 个带按压旋钮和 1 个双轴摇杆。

```text
┌─────────────┬─────────────┬─────────────┬─────────────┐
│ 旋钮        │ Agent 1     │ Agent 2     │ 摇杆        │
│ Encoder     │ AG00        │ AG01        │ Joystick    │
├─────────────┼─────────────┼─────────────┼─────────────┤
│ Agent 3     │ Agent 4     │ Agent 5     │ Agent 6     │
│ AG02        │ AG03        │ AG04        │ AG05        │
├─────────────┼─────────────┼─────────────┼─────────────┤
│ Fast Mode   │ Approve     │ Reject      │ Fork Chat   │
│ ACT06       │ ACT07       │ ACT08       │ ACT09       │
├─────────────┼───────────────────────────┼─────────────┤
│ Profile     │ Mic                       │ Submit      │
│ + 3 LEDs    │ ACT10 + ACT11             │ ACT12       │
└─────────────┴───────────────────────────┴─────────────┘
```

## 2. Agent 任务键

| 物理位置 | 显示名称 | 默认功能 |
| --- | --- | --- |
| `AG00` | Agent 1 | 打开或切换到第 1 个动态任务槽位 |
| `AG01` | Agent 2 | 打开或切换到第 2 个动态任务槽位 |
| `AG02` | Agent 3 | 打开或切换到第 3 个动态任务槽位 |
| `AG03` | Agent 4 | 打开或切换到第 4 个动态任务槽位 |
| `AG04` | Agent 5 | 打开或切换到第 5 个动态任务槽位 |
| `AG05` | Agent 6 | 打开或切换到第 6 个动态任务槽位 |

六个 Agent 键的操作方式相同：

- **单击**：切换到对应任务，但不主动抢占当前应用焦点；
- **350ms 内双击**：切换到对应任务，并将目标桌面应用唤起到前台；
- **空的自定义槽位**：交由目标桌面应用执行原生的新建任务和分配流程；
- **任务不存在或暂时无法打开**：安全失败，不切换到错误任务。

Agent 键同时通过灯光显示任务状态：

| 灯光 | 含义 |
| --- | --- |
| 熄灭 | 槽位为空 |
| 白色 | 任务空闲 |
| 蓝色动态 | 正在思考或执行 |
| 绿色 | 已完成或有未读结果 |
| 琥珀色 | 需要用户输入或确认 |
| 红色 | 任务发生错误 |
| 当前颜色轻微呼吸 | 当前选中的任务 |

## 3. 默认 Command Key

| 物理位置 | 默认键帽 | 功能说明 |
| --- | --- | --- |
| `ACT06` | Fast Mode | 开启或关闭快速模式；是否可用由当前目标应用上下文决定 |
| `ACT07` | Approve | 批准当前等待处理的请求或操作 |
| `ACT08` | Reject | 拒绝当前等待处理的请求或操作 |
| `ACT09` | Fork Chat | 从当前会话或任务创建一个分支 |
| `ACT10` + `ACT11` | Mic | 默认作为一个双宽语音键使用 |
| `ACT12` | Submit | 提交当前输入区中的内容 |

使用说明：

- 除 Mic 外，普通 Command Key 通常在按下时执行一次动作；
- Approve、Reject、Fork Chat 和 Submit 只有在当前上下文支持时才会执行；
- 键盘本身不增加额外确认弹窗，操作结果由目标桌面应用原生处理；
- 这些位置可以在 Agent Bridge App 中重新绑定为其他受支持动作、命令、Skill 或“无动作”。

### Mic 双宽语音键

默认情况下，`ACT10` 和 `ACT11` 由一个双 Stem 2U Mic 键帽覆盖，任意一侧按下都视为同一个 Mic 操作：

- **按住**：开始录音；
- **松开**：停止录音并进入处理；
- **350ms 内双击**：进入锁定录音，无须继续按住；
- **锁定后再次单击**：停止录音。

Mic 灯效由 App 根据实际录音状态下发，设备不自行猜测录音是否开始或结束。

目标设计还支持 **Split Mic Mode**：拆下双宽键帽并换成两个 1U 键帽后，`ACT10` 和 `ACT11` 可作为两个独立 Command Key。当前默认布局和当前 App 模型均使用 Combined Mic Mode。

## 4. 摇杆

摇杆为四方向模拟输入，回到中心后可以再次触发同一方向。默认功能如下：

| 方向 | 默认功能 |
| --- | --- |
| 上 | 开启或关闭 Plan Mode |
| 右 | 向前导航 |
| 下 | 显示或隐藏侧边栏 |
| 左 | 向后导航 |

四个方向可以在 App 中分别重新配置。摇杆没有按压功能；向某个方向推动只触发一次，保持不动不会连续重复执行。

## 5. 旋钮

旋钮支持逆时针旋转、顺时针旋转、按下和松开。

当前默认模式为 **Composer Navigation**：

- 旋转用于目标应用输入区的原生导航；
- 按压及长按由目标桌面应用的原生旋钮交互处理；
- 固件只报告旋转方向、步数和按压状态，不固定具体业务动作。

当前 App 还支持 **Reasoning Only** 模式，用旋转调整推理等级。Conversation Scrolling 和 Custom Assignments 属于最终硬件目标能力，不作为当前默认功能。

## 6. Profile 键

Profile 键不是普通命令键，它只负责设备连接和安全确认：

- **短按**：进入或移动连接选择，在 USB、BT1、BT2、BT3 之间选择；
- **长按 3 秒**：让当前蓝牙槽位进入重新绑定流程；
- **首次绑定时长按**：确认用户本人在设备旁，完成设备信任；
- **清除绑定**：必须经过明确长按和警示灯效，单击不会误清除。

三个白色 Profile LED 用于显示 BT1、BT2、BT3 的选择、配对和连接状态。插入 USB-C 只提供数据或供电，不会自动将当前连接模式从蓝牙切换为 USB。

## 7. 其他实体控件

- **后部电源开关**：控制主系统和灯光的上电；关闭后仍允许通过 USB 给电池充电；
- **隐藏 Recovery 键**：仅用于固件严重故障时的恢复，不属于日常操作；
- **摇杆按压**：不使用，摇杆只提供四方向输入。

## 8. 功能边界与数据说明

- 设备固件只识别物理位置，不保存每个键对应的业务动作；
- Command Key、摇杆和旋钮的具体含义由 Agent Bridge App 解析，因此修改配置通常不需要升级固件；
- 当前上下文不支持某个动作时，该按键会返回不可用，而不是伪装执行成功；
- 设备不保存账号、任务标题、会话内容、Prompt、回复、终端内容、代码差异或凭据；
- 设备灯光只接收有限状态枚举，不接收任务正文或其他业务内容。

详细软硬件边界参见 [`AGENT_BRIDGE_HARDWARE_SOFTWARE_COLLABORATION_PROTOCOL.md`](./AGENT_BRIDGE_HARDWARE_SOFTWARE_COLLABORATION_PROTOCOL.md)。
